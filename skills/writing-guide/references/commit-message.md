# 커밋 메시지

- 정해진 형식이 없으면 제목은 `접두어: 변경 내용` 형태로 쓰고 범위 괄호를 붙이지 않는다.
- 제목과 본문 항목은 명사형으로 끝낸다.
- 본문은 목록 항목으로 쓴다.
- 제목만으로 충분한 작은 변경에는 본문을 쓰지 않는다.
- 기능이 어떻게 동작하는지가 아니라 코드에 무엇을 했는지 쓴다.
  - 예) "비밀번호 재설정" → "비밀번호 재설정 메일을 보내는 API 추가"
- 함수나 API 이름은 바꾼 대상을 가리킬 때만 쓰고 그 역할을 함께 적는다.
  - 예) "parseToken() 추가" → "요청 헤더에서 인증 토큰을 꺼내는 parseToken() 추가"
- 파일 이름은 diff로 알 수 있으므로 쓰지 않는다.
- 동사는 실제로 한 일에 맞는 말을 고른다.
- diff만 봐서는 알 수 없는 이유는 그 변경을 적은 항목에 함께 쓴다.
