# 코드 주석

- ~한다체로 쓴다.
- 주석이 없을 때 누군가 잘못 되돌릴 만한 코드에만 주석을 단다.
- 코드가 하는 일이 아니라 그렇게 정한 근본 이유를 적는다.
  - 예) "// 3회 재시도한다" → "// 결제사 API가 일시적으로 실패하는 경우가 있어 3회까지 재시도한다"
- 한 주석에는 이유 하나만 적는다.
- 변경 이력이나 요청받은 경위 같은 작성 과정을 적지 않는다.
- 주석은 파일, 함수, 줄 중 그 이유가 해당하는 범위 바로 위에 둔다.
- 줄 길이 때문에 한 문장을 여러 줄로 나누지 않는다.
- 주석에 코드 블록을 넣지 않는다.
